# Artwork guidance

Official requirements checked October 18, 2026; recheck the destination when publishing.

- [Apple Show Cover](https://podcasters.apple.com/support/5514-show-cover-template): square JPG/PNG without transparency, 3000×3000 preferred; RSS accepts 1400–3000 square. Required show cover and optional episode artwork have distinct roles. An image file does not itself update an RSS feed.
- [YouTube thumbnail guidance](https://support.google.com/youtube/answer/72431?hl=en): current recommended video image is 3840×2160, 16:9; podcast playlists use square art. Size limits vary by upload surface. JPEG below 2 MB is this skill's conservative delivery choice.

Compose both layouts around the same clear idea with short text and subject/background separation. Check mobile legibility. Brand colors/type/logo come from project assets. Do not invent guests, events or endorsements. Use authorized portraits or an intentionally nonliteral concept where appropriate; inspect identity, fine text and logos. Keep tool/model/license provenance in private job notes.

The helper only checks aspect ratio and resizes/encodes; it does not design, generate, spellcheck or license images. Choose and flatten an intended background in the image tool before JPEG export. Record if generation supplied fewer pixels than delivery; simple upsampling is not detail restoration. No model, font, logo, stock asset or credential is bundled. Native generation belongs to the agent host and may use remote services; local FFmpeg encoding does not make remote image processing local.
